# iLogia Student Dashboard

This is a static HTML, CSS, and JavaScript dashboard that connects directly to Supabase through the browser SDK. It requires no npm, build process, PHP, or separate API server.

- Website: `public/`
- Supabase project configuration: `public/config.js`
- Windows local server: `run-local.bat`

See the repository [README](../../README.md) for Supabase redirect setup and GitHub Pages deployment.
